# सम्राट योद्धा फाउंडेशन — वेबसाइट

- `website/` — वेबसाइट की असली फ़ाइलें (HTML, CSS, JS, images)
- `samrat-yodha-website.zip` — यही फ़ाइलें ZIP में, जो Hostinger पर samratyodhafoundation.org में खोली जाती हैं

यह फ़ोल्डर Hostinger पर सिर्फ़ अपडेट के लिए आता है; `.htaccess` इसे बाहर से खुलने नहीं देता।
